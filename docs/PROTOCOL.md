# GlucoTwin evaluation protocol — frozen before model results

Source: CGMacros v1.0.0. Linked baseline profiles and native Dexcom observations. No meal fields in initial model: logged amounts may depend on post-meal assessment. Never use Libre as a feature. Initial endpoint: glucose 30 minutes after issue time; six 5-minute path outputs support experimental onset warnings.

Select participant splits deterministically within source-defined HbA1c cohorts (seed 20261019), approximately 60% train, 20% validation, 20% untouched test. Freeze IDs after audit and before any model predictions. Report all cohorts and Type 2 subgroup separately. Development model selection uses equal-patient validation MAE at 30 minutes, with a target of at least 5% reduction versus persistence. Final test is opened once after configuration is frozen. Report failure if the target is missed; do not tune on test.

Features use 60 minutes of history ending at issue time, plus past-only state. Published minute-level glucose is interpolated. Infer the dominant integer-valued five-minute phase using only the first 24 hours; retain that fixed phase thereafter and reject fractional/out-of-range endpoints. Preserve endpoint timestamps. This reconstruction cannot prove original native observation provenance, and unknown source interpolation across gaps remains a limitation. No forecasts or metrics during the 24-hour initialization. Activity summaries use only the preceding five minutes at each endpoint. No interpolation. Require a complete current history for supported predictions. Label timestamps must have observed glucose; do not interpolate labels. Coverage includes withheld windows.

Compare persistence; capped recent trend; regularized linear delta model; small gradient-boosted delta model; the same boosted model with clinical fields; the same model with clinical and available activity fields. No subject ID as a feature. Clinical fields: age, BMI, HbA1c, fasting glucose. Imputation fitted only on train. Uncertainty: absolute validation residual quantiles per horizon; report test coverage and width without assuming exchangeability across patients.

Adaptive variant applies a clipped exponential moving correction only when a forecast's target reading arrives. Select correction rate from {0, .03, .1} on validation; maximum absolute correction 30 mg/dL. Compare all variants on the same timestamps after each participant's first 24 hours. A gap resets history; unmatured errors never update state.

Research event: new glucose crossing strictly above 180 mg/dL with four consecutive observed five-minute values above threshold (15 minutes from first to fourth). Missing values break confirmation. New onset requires a preceding observed value <=180. Ongoing high-glucose time is excluded from warning issuance. Warn if a forecast path crosses a validation-selected threshold {170,180,190,200}, using 30-minute cooldown. Select best event sensitivity with <=0.25 false warnings per eligible non-event hour on validation; if none qualify choose lowest false-warning rate, breaking ties by sensitivity. Future 45-minute observed coverage is required to judge negative warning opportunities. At least one supported opportunity in the prior 30 minutes makes an onset eligible; separately report total observed onsets and unsupported onsets. An alert matches the nearest onset in (issue, issue+30min], at most once per event; duplicates are counted separately, not as new successes. Report false warnings, missed events, lead times, monitoring coverage, and per-patient metrics. These are research thresholds, not individualized medical targets.

No treatment dosing, causal meal simulations or Indian-population validation claims. Preserve all experiment results, failures and data-quality limitations.
